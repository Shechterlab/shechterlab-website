{{/* Countdown block — local to this site. Modelled on the premium conference template's countdown, reimplemented on the current kit (that block targets the older blox-tailwind generation and its markup does not resolve here). The important difference: this one copes with not knowing the date yet. The club announces the symposium months before it fixes a date, and a countdown that renders 00:00:00 against an unset target looks broken. With no `date`, it shows `fallback_text` instead of digits; once the date has passed, it shows `elapsed_text`. Content options date target, e.g. '2027-07-20 09:00:00'. Leave empty until known. title heading above the digits text line above the digits text_after line below the digits fallback_text shown in place of digits when `date` is empty elapsed_text shown once the target is in the past button { text, url } optional call to action Server-rendered digits are the real remaining time at build time, so a visitor with JavaScript off still sees a sensible figure rather than zeroes; the script then keeps it ticking. */}} {{ $block := .wcBlock }} {{ $content := $block.content }} {{ if not (reflect.IsMap $content) }}{{ $content = dict }}{{ end }} {{ $raw := index $content "date" }} {{ $target := "" }} {{ if $raw }}{{ $target = time $raw }}{{ end }} {{ $elapsed := false }} {{ $d := 0 }}{{ $h := 0 }}{{ $m := 0 }}{{ $s := 0 }} {{ if $target }} {{ $secs := int (div (sub $target.Unix now.Unix) 1) }} {{ if le $secs 0 }} {{ $elapsed = true }} {{ else }} {{ $d = div $secs 86400 }} {{ $h = div (mod $secs 86400) 3600 }} {{ $m = div (mod $secs 3600) 60 }} {{ $s = mod $secs 60 }} {{ end }} {{ end }}

{{ end }} {{ if not $target }}

{{ (index $content "fallback_text") | default "Date to be announced." | markdownify }}

{{ else if $elapsed }}

{{ (index $content "elapsed_text") | default "This one has been and gone." | markdownify }}

{{ else }}

{{ end }} {{ with index $content "text_after" }}
