{{/* Local override of the kit's `functions/get_event_dates`. Why: the events layout prints a Date row unconditionally for anything of type `events`, with no opt-out, and derives it from `event_start` falling back to `.Date`. An announced-but-unscheduled symposium still needs a `date:` so Hugo can sort it and count it as upcoming — which meant the page advertised a placeholder ("Jul 1, 2027") as though it were the real date. Overriding this short partial is far cheaper than forking the 285-line layout. Added: `date_text` in front matter short-circuits the calculation and is printed verbatim, so a page can read "To be announced" while still carrying a sortable `date`. Everything else is upstream's behaviour. Note the single trailing `return`: Hugo rejects `return` nested inside a `with`/`if` block, so the branches assign to $out instead. */}} {{ $date_text := .Params.date_text }} {{ $out := "" }} {{ if $date_text }} {{ $out = $date_text }} {{ else }} {{ $start_date := .Params.event_start | default .Date }} {{ $end_date := .Params.event_end | default .Params.date_end }} {{ $all_day := .Params.event_all_day | default .Params.all_day }} {{ $t1 := time $start_date }} {{ $str := slice (time.Format (site.Params.hugoblox.locale.date_format | default ":date_long") (time $t1)) }} {{ if not $all_day }}{{ $str = $str | append (time.Format (site.Params.hugoblox.locale.time_format | default "3:04 PM") (time $t1)) }}{{ end }} {{ if $end_date }} {{ $str = $str | append "—" }} {{ $t2 := time $end_date }} {{ if not (eq $t1.Year $t2.Year | and (eq $t1.Month $t2.Month) | and (eq $t1.Day $t2.Day)) }} {{ $str = $str | append (time.Format (site.Params.hugoblox.locale.date_format | default ":date_long") (time $t2)) }} {{ end }} {{ if not $all_day }}{{ $str = $str | append (time.Format (site.Params.hugoblox.locale.time_format | default "3:04 PM") (time $t2)) }}{{ end }} {{ end }} {{ $out = delimit $str " " }} {{ end }} {{ return ($out | safeHTML) }}
