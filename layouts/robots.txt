{{- /*
  Local robots.txt template (Hugo generates this because `enableRobotsTXT:
  true` is set in config/_default/hugo.yaml; without this file Hugo emits a
  bare "User-agent: *" that allows everything, which is what the site had).

  Policy: search engines and AI assistants that CITE AND LINK BACK are
  welcome. Crawlers that only harvest text into a training corpus are not.

  Two things worth knowing before editing:

  1. Under RFC 9309 a crawler obeys exactly ONE group — the one naming its
     own product token — and falls back to `User-agent: *` only when no
     group names it. So a bot listed below ignores the `*` group entirely,
     and the order of groups in this file does not matter.

  2. This is a blocklist over an open default. That keeps search engines and
     ordinary tools working without enumerating them, but it means a new
     scraper is allowed until someone adds it here. Check Netlify's traffic
     analytics occasionally and extend the list.

  robots.txt is a request, not a fence. Several of these crawlers are
  documented as ignoring it (Bytespider is the usual offender). Enforcement
  needs Netlify's user-agent blocker at the edge — see UPDATE-GUIDE.md.
*/ -}}
